# Windows 11 Icons for macOS

A collection of Windows 11-inspired icons for macOS applications and folders.

These are SVG and PNG icons that you can use to replace your Mac app icons, folder icons, and system icons with a Windows 11-inspired aesthetic.

## What's included

- **App icons** — Windows 11-style icons for popular macOS applications
- **Folder icons** — Windows 11 folder icon set
- **System icons** — Start button, settings, and utility icons
- **SVG source files** — All icons as editable SVG files
- **PNG exports** — Ready-to-use PNG versions for ICNS conversion

## How to use these icons

### On macOS

1. Right-click on an app or folder
2. Select "Get Info"
3. Drag and drop one of these icon files onto the icon in the top-left corner
4. Done!

Alternatively, you can use icon management apps like:
- **LUT Toolbox**
- **Icon Changer**
- **Iconchanger**

### Converting to ICNS format

If you want to convert these SVG or PNG icons to macOS ICNS format:

1. Use an online tool like [ConvertICO](https://convertico.com/) or [CloudConvert](https://cloudconvert.com/)
2. Upload the PNG version
3. Select "ICNS" as the output format
4. Download and apply to your apps
